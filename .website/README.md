PRISM HORN is a colorful arcade survival game created for js13kGames 2026.

Aim the unicorn's horn, switch between five laser colors, and destroy matching enemies before they reach the defense line. Earn Prism XP, choose roguelike upgrades, create multi-color beam combinations, and survive increasingly dangerous boss battles.

The game supports keyboard, mouse, and touch controls. All graphics are drawn with the Canvas 2D API, while the sound effects and BGM are generated with the Web Audio API. No external images, audio files, or libraries are used.

Keyboard:
- Left / Right or A / D: Aim
- 1–5: Select color
- Q / E: Previous or next color
- Space: Fire
- P / Esc: Pause
- M: Mute

Mouse:
- Move to aim
- Click to fire
- Mouse wheel to switch colors

Touch:
- Drag to aim
- Release to fire
- Tap the color buttons to switch colors
